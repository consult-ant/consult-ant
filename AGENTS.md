# Project UI conventions

- For portfolio and collection pages, follow [`DESIGN-SYSTEM.md`](./DESIGN-SYSTEM.md) and reuse the tokens and components in `style.css`.
- Use `.button` with a documented variant instead of adding one-off button styles. Keep links as links and actions as buttons.
- Preserve visible keyboard focus, semantic HTML, responsive behavior, and the site's reduced-motion support.
- Standalone games and visualisations may have distinct visual themes; reuse shared styles only when they fit the experience.
